## 📂 Studi Kasus Pilihan
1. **SQL Portfolio — HR Employee Attrition & Analytics**  
   Analisis 1.470 data karyawan fiksi IBM menggunakan kueri SQL relasional bertingkat untuk mengungkap korelasi beban kerja lembur (*OverTime*) terhadap rasio turnover karyawan (30.5% vs 10.4%).
2. **Excel 365 Automation — Laporan Finansial & Data Cleaning UMKM**  
   Mentransformasi 500+ baris data transaksi kotor menjadi dashboard arus kas dinamis dengan formula modern Excel 365, memangkas waktu rekonsiliasi bulanan dari 3 hari menjadi 15 menit.
3. **BukuLagi — Katalog & Pipeline Data Toko Buku Bekas Tangsel**  
   Aplikasi web katalog inventaris berbasis Python Flask dan Supabase PostgreSQL dengan integrasi pemesanan langsung via WhatsApp untuk pasar Tangerang Selatan.
4. **Personal Data Assistant — Otomasi Workflow Analis & Telegram Reporting**  
   Harness autonomous agent berbasis terminal Linux untuk eksplorasi data awal (EDA), validasi kueri SQL lokal, dan pengiriman rekapitulasi data instan ke Telegram.
