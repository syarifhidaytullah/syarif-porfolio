Personal Data Assistant: Workflow Automation & Telegram Reporting

Implementasi harness autonomous agent berbasis Linux terminal untuk akselerasi riset data, validasi kueri kueri analitik, dan pengiriman laporan otomatis ke Telegram.

Automation Hermes Agent CLI Linux Environment (Bash) Telegram Bot Gateway Local LLM Router Python

1 Latar Belakang Masalah

Aktivitas sehari-hari seorang data analyst sering kali terbebani oleh pekerjaan repetitif non-analitik: mengonversi berkas mentah, memformat tabel, memvalidasi sintaks kueri database yang panjang, dan mengirimkan file laporan secara manual ke chat manajer atau klien. Di sisi lain, menggunakan layanan AI publik di browser berisiko membocorkan kerahasiaan data internal perusahaan. Diperlukan asisten terotomasi yang beroperasi langsung di dalam lingkungan Linux lokal dengan standar keamanan data yang ketat.

2 Arsitektur Sistem & Komponen

Sistem dibangun di atas lingkungan sistem operasi Linux dengan integrasi multi-komponen:

  • Agent Core: Hermes Agent yang berjalan di CLI lokal dengan kemampuan tool-calling native (pembacaan file, regex, shell scripting).
  • Messaging Gateway: Layanan daemon gateway yang menghubungkan terminal Linux dengan Telegram Bot API secara persisten.
  • Private Local Routing: Router model bahasa lokal (OpenAI-compatible) untuk memastikan data kueri dan file analisis tetap berada di dalam infrastruktur lokal.

3 Alur Kerja & Otomasi

  1. Autonomous CLI Execution: Agent mampu membaca dataset lokal (CSV, SQLite), melakukan inspeksi tipe data, serta menguji validitas kueri SQL sebelum dijalankan ke database produksi.
  2. Two-Way Messaging: Analis dapat memicu automasi pembersihan data atau meminta ringkasan angka cukup dengan mengirimkan pesan singkat ke Telegram saat sedang tidak di depan laptop.
  3. Mobile File Delivery: Laporan dalam bentuk PDF, grafik, atau ringkasan spreadsheet langsung dikirimkan secara terenkripsi ke akun Telegram stakeholder tanpa proses upload manual.
  4. Data Governance: Seluruh pemrosesan mematuhi aturan privasi data dengan pembatasan hak akses tool di lingkungan terminal.

4 Dampak Efisiensi Kerja

  • Efisiensi Waktu: Mempercepat tahapan persiapan data awal (Exploratory Data Analysis) dan pembuatan query template hingga 40%.
  • Pelaporan Instan: Klien dan stakeholder bisnis menerima ringkasan metrik harian langsung di ponsel via Telegram secara konsisten.
  • Zero Data Leakage: Mengurangi ketergantungan pada SaaS pihak ketiga dan menjaga data mentah tetap aman di mesin lokal.

5 Nilai Tambah bagi Organisasi

Membuktikan kemampuan adaptasi terhadap teknologi agen otonom generasi terbaru (agentic AI), menggabungkan kapabilitas analisis data tradisional dengan otomasi tingkat lanjut di lingkungan sistem Linux.
